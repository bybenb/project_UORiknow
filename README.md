# UORiknow

Um website para estudar minhas disciplinas. Como user normal, entrando no site, poderás ver e escolher a cadeira (disciplina) que queres estudar. Clicando-a, abres um set de quest como nessa imagem (essa é da disciplina "Direito Informático"). Interativos e sonoro deve ser, e com algumas animações.


## Stack

Usei o óbvio trio indispenssável em webdev, mas para JS e CSS, cheguei de precisar Bootstrap e FontAwesome.
Em termos de backend, usei o framework FastAPI da linguagem Python bem como o SQL-Alchemy (um ORM) sendo que trabalhei com PostgreSQL.
